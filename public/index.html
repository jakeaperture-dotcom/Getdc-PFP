Quick tutorial

How to download a Discord profile picture

New to Discord user IDs? Follow these three simple steps to find one, look up the profile, and save the full-size avatar.

  1. 1

    Enable Developer Mode

    Open User Settings, choose Advanced, and turn on Developer Mode. You only need to do this once.

  2. 2

    Copy the user ID

    Right-click the person, or open their profile menu on mobile, then choose Copy User ID.

  3. 3

    Look up and download

    Paste the ID into the field above and select Look up. Open the avatar to view it or use Download avatar to save it.

How it works

When you select Look up, GetDC PFP sends the public user ID to our server. The server requests the public profile data from the lookup provider and returns the Discord-hosted avatar address.

Your Discord account stays separate. We never ask for a login, password, or user token, and the tool cannot access private messages.
